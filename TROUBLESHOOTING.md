# Tide troubleshooting

- Python 3 must be available as python3. No pip packages or FRED API key are required.
- Saved or overdue labels distinguish retained releases from a successful fresh download. Reporting periods matter; these are not live market prices.
- Reduced motion shows a static wrapping grid so every indicator remains readable. Leave space for its larger height or use region placement.

Use the README for settings, dependencies, privacy and sources. For a bug report, include your device, MagicMirror and Node versions, the observed behavior and a minimal configuration with secrets removed. Do not post private feeds, tokens, precise home coordinates or network snapshots.
